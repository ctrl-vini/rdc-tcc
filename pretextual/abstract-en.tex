\begin{resumo}[Abstract]
  \begin{otherlanguage*}{english}
    This work presents the development of Duckoder, a web platform integrated with a locally hosted large language model (LLM) to help students program educational embedded systems boards. The solution consists of a web interface, a REST API that automatically adds the board's hardware description to each request, and an open model running on a local network server, with no need for cloud services. The evaluation uses a set of hands-on activities executed on the board and considers the rate of working code and the model's response time. \placeholder{Traduzir os resultados e a conclusão da versão final do resumo.}
