\begin{resumo}[Abstract]
  \begin{otherlanguage*}{english}
    This work presents the development of Duckoder, a web platform integrated with a locally hosted large language model (LLM) to help students program educational embedded systems boards. The solution consists of a web interface, where the student chooses the board, describes the activity in natural language and refines the code in the same conversation; a REST API that automatically adds the board's hardware description to each request and keeps the conversation history; and an open model running on a local network server through Ollama, with no need for cloud services. The evaluation used ten hands-on activities of increasing complexity, split between the ESP32 and the Arduino Mega 2560 and submitted three times to two models, Qwen2.5-Coder 7B and Llama 3.1 8B, and considered the rate of working code and the response time. Qwen2.5-Coder produced working code in the first answer in 83\% of the generations and in 87\% after refinement; Llama 3.1, in 67\% and 77\%, respectively. All generations for the low-complexity activities worked in the first answer, and the failures were concentrated on specific libraries. Refinement through the conversation recovered part of the compilation errors, but none of the programs that compiled and behaved differently from what was requested. The mean response time was between 12 and 14~s, and communication over the local network added only milliseconds. The results show that an open model running on the institution's own infrastructure is enough for the activities of introductory courses, without depending on an external connection, with no cost per request and keeping the data within the institution.

    \vspace{\onelineskip}

    \noindent\textbf{Keywords:} embedded systems; large language models; web application; local network; education.
  \end{otherlanguage*}
\end{resumo}
